Kom igång

  1. Skapa en nyckel under Nycklar och tak och spara den hos er, till exempel i miljövariabeln ADX_SMS_KEY.
  2. Skicka ett sms med ett anrop till POST {{ api_base }}/messages/.
  3. Följ sms:et här i portalen, eller hämta det med GET {{ api_base }}/messages/<id>/.

Nyckeln hör hemma på er server. Lägg den aldrig i JavaScript som körs i besökarens webbläsare eller i en app: den som har nyckeln kan skicka sms på ert konto. Har den kommit ut, återkalla den och skapa en ny.

Skicka ett sms

POST {{ api_base }}/messages/

Kroppen är JSON. Huvudet Authorization: Bearer <nyckel> krävs i varje anrop.

FältKrävsBetydelse
tojaMottagarens mobilnummer, helst i internationell form (+46701740605). Ett nummer utan landsnummer (0701740605) tolkas som svenskt.
messagejaTexten. Högst {{ max_parts }} sms-delar, se Tecken och delar.
fromnejAvsändaren. Utelämna den, eller skicka exakt {{ account.sender_name }}; allt annat stoppas.
referencenejEr egen id för sms:et, 1-64 tecken (a-z, A-Z, 0-9 och . _ : -). Samma reference två gånger ger samma sms tillbaka i stället för ett nytt, så ett nytt försök efter ett avbrutet anrop skickar aldrig dubbelt. Rekommenderas.
dryrunnejtrue provkör: svaret visar land, delar och pris, men inget skickas och inget kostar.

curl

curl -X POST {{ api_base }}/messages/ \
  -H "Authorization: Bearer $ADX_SMS_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to": "+46701740605", "from": "{{ account.sender_name }}", "message": "Hej! Din tid är bokad till torsdag kl 14.00.", "reference": "bokning-1042"}'

const data = await response.json();
if (!response.ok) {

Svaret

201 när sms:et lämnats till operatören, 200 när samma reference redan fanns (då med "duplicate": true).

202 med status unknown och felkoden provider_unknown när leverantören inte svarade säkert: sms:et kan ha skickats. Skicka det inte igen med en ny reference. Ett nytt anrop med samma reference ger samma sms tillbaka och skickar aldrig igen. ADX stämmer av läget, och sms:et får sedan status sent, delivered eller failed; hämta det med GET för att se det. Över en gräns svarar API:t rate_limited (HTTP 429) med huvudet Retry-After: så många sekunder ska ni vänta. Det kan också hända när många av ADX kunder skickar samtidigt, eftersom leverantören har en gräns för ADX alla sms tillsammans.

Tecken och delar

Ett sms rymmer 160 tecken ur GSM-alfabetet (a-z, siffror, å ä ö é ü och vanliga skiljetecken). Ett längre sms delas i delar om 153 tecken, och varje del kostar som ett sms. Klammerparenteser, hakparenteser och tecknen ~ ^ \ | € tar två platser var.

Finns ett enda tecken utanför GSM-alfabetet, till exempel en emoji eller typografiska citattecken, skickas hela texten som UCS-2: 70 tecken per sms, eller 67 per del. Svaret visar vilken kodning som användes (encoding) och hur många delar det blev.

Pris och underlag

Varje sms kostar leverantörens pris per del till mottagarens land plus {{ markup }} öre per del. Till det kommer en årsavgift på {{ fee }} kr, som står på underlaget för den månad tjänsteåret börjar. Ett stoppat sms kostar inget. ADX fakturerar i efterhand per månad, utifrån månadsunderlaget. Alla belopp är utan moms.

Kontot får skicka till: {% for code, name in country_names %}{{ name }} ({{ code }}){% if not forloop.last %}, {% endif %}{% endfor %}. Spärren mot andra länder skyddar mot sms-pumpning, där någon låter ett formulär skicka sms till dyra nummer utomlands.
