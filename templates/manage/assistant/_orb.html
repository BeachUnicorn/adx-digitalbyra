{% comment %} AI-orben. Ren CSS - inga bilder, inget JS, ingen extern begäran. Tre suddade fläckar som roterar i olika takt bakom en cirkel med overflow: hidden. Att de rör sig olika fort är hela tricket: samma hastighet läser som ett snurrande hjul, olika hastighet läser som moln. Använd `m-orb--sm` i menyn, `m-orb--lg` i chatten. `is-thinking` snabbar upp rörelsen medan en tur pågår. {% endcomment %}
