Inställningen i Google Cloud

Projektet och OAuth-klienten

  1. Google Cloud Console, projektet som ska äga OAuth-klienten: slå på Google Ads API under API:er och tjänster. Projektet börjar med Test-åtkomst, som bara når testkonton.
  2. Ansök om Explorer på sidan Google Ads API Overview för projektet (inte i förvaltarkontots API Center, där behandlas inget längre). Explorer når riktiga konton men får inte skapa konton åt kunder.
  3. För "Skapa ett konto åt kunden": verifiera projektets varumärke och ansök om Basic på samma sida.
  4. Skapa en OAuth-klient av typen webbapp och lägg till adressen nedan som godkänd omdirigering (Authorized redirect URI), exakt som den står.
  5. Lägg klientens id och hemlighet i miljön som GOOGLE_ADS_CLIENT_ID och GOOGLE_ADS_CLIENT_SECRET. Utvecklartoken behövs inte: Google bortser från den sedan 2026-09-09.
  6. Koppla med Google här, med ett Google-konto som har åtkomst till förvaltarkontot.
