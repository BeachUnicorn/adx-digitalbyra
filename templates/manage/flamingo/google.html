Inställningen i Google Cloud

Projektet och OAuth-klienten

  1. Google Cloud Console, projektet som ska äga OAuth-klienten: slå på Google Ads API under API:er och tjänster. Projektet börjar med Test-åtkomst, som bara når testkonton.
  2. Slå på Data Manager API i samma projekt. Konverteringarna går den vägen; utan den går de som CSV.
  3. Ansök om Explorer på sidan Google Ads API Overview för projektet (inte i förvaltarkontots API Center, där behandlas inget längre). Explorer når riktiga konton men får inte skapa konton åt kunder.
  4. För "Skapa ett konto åt kunden": verifiera projektets varumärke och ansök om Basic på samma sida.
  5. Skapa en OAuth-klient av typen webbapp och lägg till adressen nedan som godkänd omdirigering (Authorized redirect URI), exakt som den står.
  6. Lägg klientens id och hemlighet i miljön som GOOGLE_ADS_CLIENT_ID och GOOGLE_ADS_CLIENT_SECRET. Utvecklartoken behövs inte: Google bortser från den sedan 2026-09-09.
  7. På samtyckesskärmen (OAuth consent screen) ska behörigheterna för Google Ads API och Data Manager API finnas med. Data Manager-behörigheten är känslig: med användartypen Extern ska appen verifieras av Google innan den används i produktion. Med Intern, inom en Google Workspace-organisation, behövs ingen verifiering.
  8. Koppla med Google här, med ett Google-konto som har åtkomst till förvaltarkontot, och låt rutorna för Google Ads och Data Manager vara ikryssade. En koppling från innan Data Manager API kopplas om en gång.
  9. För övervakningen: slå på Google Search Console API, Chrome UX Report API, My Business Account Management API, My Business Business Information API, Business Profile Performance API och Google My Business API i samma projekt, och lägg till behörigheterna för Search Console (webmasters.readonly) och Business Profile (business.manage) på samtyckesskärmen. Koppla sedan om en gång.
